What It Does

Classify

Matches each file to your firm's own client list and document types. It never invents a client.

File

Renames to a standardized, searchable name and routes it automatically. Every move is logged.

Review

Anything low-confidence is set aside for a human. Duplicates are caught by content, not filename.
